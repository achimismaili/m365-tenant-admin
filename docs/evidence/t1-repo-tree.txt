7. GITIGNORE BEHAVIOUR
--------------------------------------------------------------------------------

docs/evidence/raw/ is excluded via the pattern `docs/evidence/raw/*` rather than
a bare `docs/evidence/raw/`. This is deliberate: git does not descend into an
excluded directory, so a bare directory pattern would make the negation
`!docs/evidence/raw/.gitkeep` unusable and the directory would be absent from a
fresh clone. With the /* form, the directory exists in a clone, the .gitkeep is
tracked, and every other file inside it is ignored.

Also excluded: *-raw.json, *-raw.xml, *-raw.csv, *-raw.txt, *-secret.*, *.secret,
secrets.json, .env, and the usual credential/certificate extensions
(*.pfx *.p12 *.pem *.key *.cer *.crt).
