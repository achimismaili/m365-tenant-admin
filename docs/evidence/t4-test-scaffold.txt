K. Known environment limitation found while testing
==============================================================================

On this host the SharePoint reads and the Azure reads cannot run in the same
PowerShell edition:

  PowerShell 7.6.5   Microsoft.Online.SharePoint.PowerShell -> TypeLoadException
                     (no CompatiblePSEditions; cannot load under Core)
                     Az.Accounts 5.3.2                      -> loads, context readable
                     Az.Billing 2.3.0                       -> demands Az.Accounts 5.5.0,
                                                               which is not installed

  Windows PS 5.1     Microsoft.Online.SharePoint.PowerShell -> loads, Get-SPOTenant reachable
                     Az.Accounts 5.3.2                      -> Get-AzContext throws
                                                               MissingMethodException
                                                               (get_SerializationSettings)

The verifier degrades each affected check to [MANUAL] independently instead of
failing, so it still produces a useful report in either edition. A live T6 run
either needs two passes, or the Az module set repaired first:
  Install-Module Az.Accounts -RequiredVersion 5.5.0 -Scope CurrentUser -Force
